# ✈️ Sid Airlines - Airline Booking System

A modern airline booking web application built using PHP, MySQL, Bootstrap, HTML, CSS, and JavaScript.

## 🌐 Live Demo

🔗 [http://sid-heree.infinityfreeapp.com](http://sid-heree.infinityfreeapp.com)

---

## 📌 Features

* User-friendly flight booking interface
* Search flights by:

  * Departure city
  * Destination city
  * Travel date
  * Preferred airline
* View all available flights
* Flight seat selection system
* Booking confirmation page
* My Trips section
* Responsive modern UI
* MySQL database integration
* 500+ flight dataset included

## 🚀 How To Run Locally

### 1. Install XAMPP

Download and install XAMPP:
[https://www.apachefriends.org/](https://www.apachefriends.org/)

### 2. Move Project

Place the project folder inside:

```bash
xampp/htdocs/
```

### 3. Start Services

Open XAMPP Control Panel and start:

* Apache
* MySQL

### 4. Import Database

1. Open phpMyAdmin
2. Create database:

```sql
airline
```

3. Import SQL file

### 5. Run Project

Open browser:

```bash
http://localhost/airline-booking-system-main/
```
